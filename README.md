# D3.js Firebase Materialize Tree Diagram

## Overview
This application visualizes hierarchical data using a tree diagram built with D3.js and styled with Materialize CSS. It fetches data from Firebase and displays it in an interactive format.

## Features
- Interactive tree diagram
- Data fetched from Firebase

## Installation
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd d3js-firebase-materialize-tree-diagram
   ```
3. Open `index.html` in your browser.

## Usage
- Ensure you have a Firebase project set up and replace the Firebase configuration in `db.js` with your project's credentials.
- Modify the data structure in Firebase to match the expected format for the tree diagram.
